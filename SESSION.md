## 2026-07-29 — VideoSpeed: cross-frame speed control for embedded/fullscreen video
Fixed `videospeed` so Alt+↑/↓ works when the actual `<video>` lives in a cross-origin iframe (e.g. an embedded YouTube player) that never receives keyboard focus: the content script now broadcasts the speed delta via `chrome.runtime.sendMessage` to `background.js`, which relays it to every frame in the tab (`content_scripts` already runs with `all_frames: true`) so whichever frame actually owns the video applies the change. Also filtered `getActiveVideo()` to only consider videos with non-zero `clientWidth`/`clientHeight`, since hidden/off-screen `<video>` elements were otherwise being picked over the real one.

## 2026-07-29 — VideoSpeed: ad auto-skip via chrome.debugger
Iterated on the `videospeed` extension's YouTube ad-skip feature through several rounds of live debugging (wrong `.html5-video-player` selector, YouTube resetting `playbackRate` during ads, an overly-broad ad-detection selector forcing 4x on normal page load). Landed on scoping ad detection to `#movie_player`'s `ad-showing`/`ad-interrupting` classes, tracking the user's chosen speed separately from `video.playbackRate` (since YouTube clobbers it), and using `chrome.debugger` (CDP trusted mouse events) to click the skip button since synthetic `.click()` events report `isTrusted: false` and YouTube ignores them — this is a hard boundary with a non-suppressible native "started debugging this browser" banner, no workaround exists. Also switched the keymap from Ctrl+↑/↓ to Alt+↑/↓, and added a VideoSpeed section to README.md.
